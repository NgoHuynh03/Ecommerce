# WEB Thương mại điện tử (Next.js)
1. Cài đặt thư viện:
npm install
2. Khởi chạy server:
npm run dev
3. Truy cập website:
http://localhost:3000

## Quản lý Database (Prisma)

Chạy lệnh sau để mở giao diện quản lý dữ liệu:
npx prisma studio

 Prisma Studio cho phép:

* Xem dữ liệu trực tiếp
* Thêm / sửa / xóa dữ liệu
* Quản lý bảng dễ dàng
